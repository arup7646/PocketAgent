# PocketAgent

A multi-agent mobile coding IDE for Android. Run Claude Code, Aider, opencode, Codex, and Gemini CLI — all on your phone via PRoot Linux.

## Features
- Multiple coding agents in one app
- On-device Linux runtime (PRoot, no root)
- Chat UI with diff viewer
- File editor with syntax highlighting
- Integrated terminal
- Web preview

## Build
GitHub Actions builds APKs automatically on every push to `main`.

## Agents Supported
- Claude Code (Anthropic)
- Aider
- opencode
- Codex CLI (OpenAI)
- Gemini CLI (Google)
